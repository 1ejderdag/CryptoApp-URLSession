# 📱 CryptoApp – Live Cryptocurrency Prices with SwiftUI

CryptoApp is a simple iOS application that displays real-time cryptocurrency prices using the CoinGecko API. It's built with SwiftUI and follows the MVVM architecture.

## 🚀 Features

- Fetches real-time market data from CoinGecko API
- Automatically updates prices every 10 seconds
- Clean and minimal SwiftUI user interface
- TRY currency support (Turkish Lira)
- Basic error handling for network issues

## 🛠️ Tech Stack

- Swift 5
- SwiftUI
- MVVM Architecture
- URLSession
- Timer (for live updates)
